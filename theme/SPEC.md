# Site OS — спецификация визуального стиля (этап 0)

Источники: 4 референса из `assets/reference/`. Два из них содержат окна-«вымогатели» (RANS0M / YOUR FILES HAVE BEEN ENCRYPTED) — они **исключены** из спецификации и из сборки. Из них используется только фон и иконки рабочего стола.

Статус значений:
- **[оценка]** — оценено на глаз по сжатому JPEG/PNG, точность ±8 по каналу. Уточнить пипеткой на скриншоте в исходном разрешении.
- **[решение]** — выбрано нами, а не снято с референса.

### 1.1 Итоговые непрозрачные цвета (без альфы, для GTK-CSS)

Расчёт: альфа-композит на фон стола `#3A4550`. Прозрачность в CSS не используется для строк и тела окна.

| Роль | Непрозрачный HEX |
|---|---|
| Тело окна Thunar (`#8A8FB0` @70%) | `#727993` |
| Строка чётная (`#9296B5` @60%) | `#6F768D` |
| Строка нечётная (`#7D82A3` @60%) | `#626A82` |
| Выделение (пересчитано, см. контраст) | `#5E6688` |

Контраст: исходное выделение `#8A90AB` давало 2.62:1 с `#E8EAF0` — не проходит. Принято `#5E6688` (4.68:1).

Прозрачность остаётся только у рамки окна и панели (композитор).

## 2. Шрифты

Основной: **VT323** (OFL, файл `assets/fonts/VT323-Regular.ttf`, устанавливается в `/usr/share/fonts/truetype/siteos/`). Запасной: **DejaVu Sans Mono** (`fonts-dejavu-core`). Unscii не используется: пакета `fonts-unscii` нет в Ubuntu noble (проверено по packages.ubuntu.com; сборка ISO на нём упала). Terminus не используется (bitmap, Pango его не рисует).

Шаг `install.sh --step fonts` только печатает предупреждения, если `fc-list | grep -i vt323` ничего не нашёл или нет ru-покрытия. Не проверено в VM.
## 2.1 Локализация

- ru/en через локаль (`LANG`) и gettext, без жёстких подписей в файлах темы.
- Для новых профилей — `/etc/skel` с конфигами; языковые строки меню в этапе 2.
- Жёстких подписей «Начать / Настройки» в CSS и XML нет.

## 2.2 Запасной вариант рамки xfwm4 (не проверено в VM)

Основной: полупрозрачная рамка через XPM-маску. Если в VM она не отрисовывается (чёрный фон, отсутствие альфы):
- рамка сплошная, непрозрачная (`#4B5562`, `#3A4550`), без XPM-альфы;
- прозрачность окна задаётся композитором через `_NET_WM_WINDOW_OPACITY` (xfwm4 «Opacity» на вкладке Compositor, значение 85–90%);
- конфиг: `use_compositing=true` в `xfwm4.xml`, `frame_opacity` в `themerc` не используется.

## 6. Окна и компоненты

- **Рамка окна**: полупрозрачная тёмно-серо-синяя, без скругления, тонкая светлая обводка 1 px.
- **Заголовок**: моноширинный текст слева, справа две круглые кнопки (свернуть и закрыть), вместо трёх.
- **Список Thunar**: колонки «Имя», «Тип», «Размер». Первая строка `..` с иконкой папки. Чередование полос.
- **Заголовок окна Thunar**: в формате `File Explorer - <путь>\` (пример: `File Explorer - Desktop\Site\`).
- **Меню «Пуск»**: светлый блок поверх панели, сверху заголовок «Начать» / «Start», список `Programs ▸`, `Favorites ▸`, `Настройки` / `Settings`, `Help`. Внизу: имя пользователя слева, справа кнопки «наверх» и «выкл».

## 7. Что не включается в сборку

- Окна с текстом «YOUR FILES HAVE BEEN ENCRYPTED», таймер, адрес оплаты, кнопка Copy — не делаем.
- Файлы с расширением `.RANSOM` в списках и на рабочем столе — не создаём. В списке Thunar используем обычные имена файлов.

## 8. Открытые вопросы

1. Нужно ли сохранять русские подписи «Начать / Настройки» как в референсе, или переключаем язык через `/etc/skel` и локаль?
2. Выбрать шрифт окончательно: VT323 (пиксельный, без кириллицы) или Share Tech Mono (с кириллицей, менее пиксельный)?
3. Пришлите исходные скриншоты рабочего стола и панели в полном разрешении, если есть. Тогда HEX и размеры уточним пипеткой.

## gen_theme.py: значения, которые не являются прямым переносом

- jgmenu не умеет градиенты. Фон меню: средний цвет `gradients.menu` = `#4E6376`.
- ANSI-палитра терминала выведена, в макете есть только фон и текст.
- Hover кнопок окна: `brightness(1.3)` из макета, применён к `btn` и `btnClose`.
- Все значения помечены "не проверено в VM".
